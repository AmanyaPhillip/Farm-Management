# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] — 2026-07-08

### Added
- Cattle registration with name, breed, farm, and alive/deceased status.
- Local SQLite storage via `sqflite` — fully offline, no internet required.
- Login screen as the app entry point.
- Import and export of cattle records as JSON via file picker / file saver.
- Vaccination, tick-dipping, milk-yield, and lineage record tracking.
- Cross-platform builds: Android, iOS, and Web.
